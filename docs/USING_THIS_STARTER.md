# Using this starter

1. Unzip `CampusFind.zip` and open the `CampusFind/` folder as your repository root.
2. Give the coding agent `AGENTS.md`, `docs/PROJECT_CONTEXT.md`, `docs/DECISIONS.md`, and `docs/OPEN_QUESTIONS.md` as its starting context.
3. Ask it to work on the next unchecked task in `TASKS.md` only, and to update docs/status with evidence.
4. Start with backend foundation. Do not ask it to build frontend flows until `docs/ROADMAP.md` backend gate is satisfied.
5. Review owner decisions before setting values or providers for open questions.

The folders contain placeholders; this ZIP does not include a running application or selected deployment credentials.
